# Standing Instruction: Commonwealth English Spelling

All manuscripts, tables, documentation, code comments, and project artifacts must strictly adhere to Commonwealth (British/International) English spelling conventions.

## Rules
1. **-ise / -isation**: Use *-ise*, *-ised*, *-ising*, *-isation* instead of *-ize*, *-ized*, *-izing*, *-ization* (e.g., *analysed*, *characterised*, *tokenisation*, *realisation*, *standardised*, *formalisation*, *romanisation*, *parsimonious*).
2. **-our**: Use *-our* instead of *-or* (e.g., *behaviour*, *colour*, *honour*, *favour*, *neighbour*).
3. **Double Consonants**: Use doubled consonants for inflected forms (e.g., *modelling*, *labelled*, *travelled*, *cancelling*).
4. **-re**: Use *-re* instead of *-er* where appropriate (e.g., *centre*). Note: LaTeX macro `\centering` is untouched.
5. **Exceptions**:
   - The phrase "an optimal context-conditional classifier" preserves "optimal" in its mathematical Bayes-optimal decision sense.
   - Verbatim titles and quotes from published external literature.
   - Code keywords, library names, or LaTeX macros (e.g., `\resizebox`, `\centering`, `\begin{itemize}`).
